### 🚀 Overview
**Chakravyuh** is a full-featured, production-ready sports-fest and event management portal built for **IMS Engineering College (IMSEC)**. It includes a public event discovery site, participant registration system with privacy-safe tracking, real-time schedule announcements, and a role-controlled admin workspace.

---

### ✨ Key Features

- 🏆 **Public Event Directory**: Interactive sports directory, event rules, schedules, gallery, and announcement feeds.
- 🔒 **Privacy-Safe Tracking**: Unique tracking codes for participant status without exposing student emails or roll numbers.
- 👑 **Role-Based Admin Portal**: Granular access control for Super Admins and Event Coordinators (manage registrations, export CSVs, update schedules).
- ⚡ **Firebase & Local Storage Support**: Real-time Firestore mode for production and local storage mode for rapid testing.
- 🛡️ **App Check & Security Rules**: Tight security rules ensuring only authorized coordinators manage assigned sports.

---

### 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend & Database**: Firebase Authentication, Cloud Firestore, Firebase Storage
- **Deployment**: Vercel

### 💻 Local Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Vatsalgoyal7/Chakravyuh.git
   cd Chakravyuh
   ```

2. **Environment Variables**:
   Copy `.env.example` to `.env.local` and add your Firebase configuration keys.

3. **Install & Run**:
   ```bash
   npm install
   npm run dev
   ```
