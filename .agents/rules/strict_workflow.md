# Strict Developer & Agent Workflow Rules

## Core Operational Directives (STRICT)

1. **NO UNAPPROVED CODE CHANGES**:
   - Never modify any existing file, feature, or database logic unless explicitly requested by the USER.
   - Do NOT touch or refactor unrelated files or existing working features under any circumstances.

2. **MANDATORY PRE-EXECUTION DISCUSSION & PLAN APPROVAL**:
   - Before executing ANY code changes or file modifications, ALWAYS output a comprehensive breakdown explaining:
     a) Exactly what was understood from the user's request.
     b) Potential add-on features, recommendations, or edge cases.
     c) The exact list of files to be modified and the precise changes planned.
   - **STOP & WAIT FOR EXPLICIT USER APPROVAL** before making any code modifications.

3. **APPLICABILITY**:
   - These rules apply strictly to ALL current and future projects (new or existing).
